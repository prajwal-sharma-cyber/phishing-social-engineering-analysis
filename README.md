# Phishing and Social Engineering Analysis

A defensive security-awareness project analysing how phishing messages use urgency, impersonation, suspicious links and social-engineering techniques.

> This project is educational. It does not create or send real phishing messages.

## Objectives
- Identify common phishing indicators.
- Understand social-engineering techniques.
- Build a safe email-analysis checklist.
- Recommend user and technical controls.

## Analysis Framework
`Sender → Context → Language → Links → Attachments → Request → Verification`

## Defensive Controls
MFA, email filtering, URL protection, security awareness training, reporting mechanisms, domain protection and least privilege.

## Skills
Threat awareness, security analysis, human factors and incident reporting.
